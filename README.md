# Чат-бот

Клиентский чат-бот с математическими операциями. Приложение работает в браузере на HTML, CSS и JavaScript.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Начало общения |
| `/name: Вася` | Задать имя |
| `/numbers: 4, 6, 10` | Задать числа для вычислений |
| `+` | Сумма |
| `-` | Вычитание всех следующих чисел из первого |
| `*` | Произведение |
| `/` | Последовательное деление |
| `gcd` | Наибольший общий делитель |
| `avg` | Среднее арифметическое |
| `min` | Минимальное значение |
| `max` | Максимальное значение |
| `/set: x = 100` | Сохранить целое число в переменную |
| `/stop` | Завершить общение |
| `/undo` | Отменить последнюю пару сообщений |

Числа можно разделять запятыми, пробелами и точкой с запятой. 

Для целочисленных диапазонов предусмотрена запись `10..15` или `10...15`, включая обе границы. 

Допускается смешивание разных форматов: `/numbers: 5, 10...15, 20`.

После операции результат сохраняется в переменной `ans`. Переменные, сохранённые через `/set`, также можно использовать в `/numbers`.

Пример:

```text
/start
/name: Вася
/numbers: 10, 20
+
Результат: 30
/numbers: ans, 2
*
Результат: 60
/set: x = 100
/numbers: x, 125
+
Результат: 225
```

При некорректном диапазоне бот сообщает об ошибке формата, при вводе некорректного числа - о необходимости вводить целые числа, при делении на ноль - об ошибке деления.

Стрелки вверх и вниз в поле ввода позволяют переключаться между ранее отправленными командами.

## Файлы проекта

- `index.html` - интерфейс чата.
- `css/style.css` - оформление и адаптивность.
- `js/chatbot.js` - команды, переменные и вычисления.
- `js/app.js` - обработка ввода и отображение сообщений.
- `assets/` - аватары и иконка кнопки отправки.
